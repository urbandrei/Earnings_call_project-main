% (a) day-0 anchor: the earnings release (8-K) precedes the market open for most calls, so the
%     call-date anchor leaves the reaction session inside the pre window;
% (b) company overlap: a time-ordered split keeps the same companies on both sides, a
%     company-disjoint split does not. Total width is kept under \textwidth (16 cm).

\caption{\textbf{Two properties of the shared test files.} (a)~Most companies

session in which the market reacts inside the pre window; the benchmark anchors on
the measured release time. (b)~A time-ordered split keeps the same companies on both
sides of the boundary; the benchmark adds a company-disjoint split and swap checks
that make the difference measurable.}
