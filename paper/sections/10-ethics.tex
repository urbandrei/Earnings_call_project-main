\section*{Ethics Statement}
\addcontentsline{toc}{section}{Ethics Statement}

\textbf{Data and licensing.} We use openly licensed corpora (FinCall-Surprise,
Apache-2.0; MAEC, CC-BY-SA-4.0; Earnings25, CC-BY-4.0) and open-weight models;
derived features inherit and state their upstream license, and raw audio or
transcripts from sources with unclear terms (EC, DEC, the reproduced repositories)
are never redistributed. Calls are public corporate disclosures; we release no
speaker-level audio or identity, only pooled per-call features. \textbf{Gender
confound.} Audio features encode speaker gender and female executives are
underrepresented in these corpora \citep{ama2024,emobias2024,docfin2022}; we report
a gender-confound diagnostic rather than silently propagate the bias.
\textbf{Intended use.} This is a forecasting-research benchmark, not investment
advice; predictions are noisy and regime-sensitive and should not drive automated
trading. \textbf{Reproducibility.} Given the documented reproducibility crisis in
financial NLP \citep{finnlp2025survey}, the environment is pinned, every data file is
checksummed, and every result table regenerates byte-identically from committed
artifacts with a run manifest.
