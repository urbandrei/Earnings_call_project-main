\section*{Contents and provenance}

This supplement holds the complete result grids behind the main paper. Every
table is generated byte for byte by \texttt{ecvol report} from the released CSVs
under \texttt{data/results/}, each of which carries a run record (resolved config,
git commit, seeds and file hash) that \texttt{ecvol runs verify} checks. The grids
span both corpora (FinCall-Surprise and MAEC), the level and \dv{} targets, the
\Rtwo{} and MSE metrics, and the temporal and \tickerdisjoint{} splits at all
horizons. Result Table 1 carries both horizon definitions and the train-mean
constant. Result Tables 2--4 use the trading-day definition and report
Diebold--Mariano $p$-values against persistence, the previous stage and the
constant. The main paper's tables copy or summarise cells from these grids.

(\texttt{result\_table\_7*.csv}), the Earnings25 audio tables and the control
tables are released as CSVs with the same provenance and are summarised in the
main paper and its appendix.
