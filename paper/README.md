# Paper — `ecvol-bench`: an identity-controlled benchmark for multimodal earnings-call volatility prediction

**Condensed 5-page spine (2026-10-09).** External feedback on the 30-page draft was
"too long and too difficult to read; shorten to 5 pages". The main text (abstract through
Discussion and Conclusion) now fits five pages of the self-contained 10pt two-column
layout; Limitations, Ethical Considerations, references and a long appendix follow. The long draft is
preserved as git tag `paper-long-2026-10-09` and as `archive/main_long_2026-10-09.pdf`.

The benchmark is the headline contribution (DECISIONS 2026-08-23 §1, 2026-08-26 §3); the
Stage 0–4 results, the reproduction study and the post-cutoff test are the evidence for
why it is needed. Every number traces to a manifested result CSV (`ecvol runs verify`).

- **Format:** official ACL style (`acl.sty`, `acl_natbib.bst`, fetched 2026-10-09 from
  github.com/acl-org/acl-style-files), `\usepackage[review]{acl}` for the anonymous,
  line-numbered ARR submission; switch to `preprint` or `final` in `main.tex` as needed.
  Target venue: ACL via ARR (`venue_memo_2026-10.md`). In this template the main text
  ends on page 8 (the ARR long-paper limit); Limitations, Ethical Considerations,
  references and the appendix are not counted.
- **Main-text structure:** Introduction (with contributions and a compact related-work
  paragraph) → The Shared Test Files and the Benchmark → Models, Protocol and Checks →
  Results → Discussion → Recommendations and Outlook (added 2026-10-09 at the advisor's
  request: framed as an analysis with new controls plus a checklist and concrete
  directions, not a verdict on prior work; main text may run to ~5.5 pages). Five
  main-text tables: substrate audit, the
  ladder grid, identity controls, the reproduced models under our controls, and the
  post-cutoff evaluation.
- **Appendix (`sections/A1-complete-results.tex`):** pipeline figure, full head sets
  (baselines, text, audio), horizon-convention delta, the reproduction study in detail
  (HTML head, faithful runs, controls, code-availability audit), Earnings25 bitrate
  study, and the call-date-anchor variant of the post-cutoff test. Wide tables are
  `table*`; everything fits its column (0 overfull boxes outside the bibliography).
- **Supplement (`supplement.tex` → `supplement.pdf`, one column):** the complete generated
  grids (Result Tables 1–4, ~70 small tables). Split off 2026-10-09 (DECISIONS) because
  ACL reviewers are not required to read appendices, supplementary material is a separate
  upload, and the two-column grids overlapped each other. Nothing was dropped: the
  supplement is committed, built by the same script, and can be handed over on request.

## Overleaf

`bash paper/make_overleaf.sh` stages a self-contained copy (main.tex, refs.bib, sections,
tables, figures, OVERLEAF.md, supplement.pdf), test-compiles it with pdflatex + bibtex
away from the repository, and writes `paper/dist/ecvol-paper-overleaf-<sha>.zip`
(gitignored). Upload it as a new Overleaf project; `OVERLEAF.md` inside explains what is
hand-written and what is generated, and how to bring edits back. First upload:
2026-10-09, project "ecvol-paper-overleaf-82d1500".

## Build

```sh
bash paper/build.sh              # -> paper/main.pdf (latexmk if perl is present, else pdflatex+bibtex)
bash paper/build.sh supplement   # -> paper/supplement.pdf
bash paper/build.sh all          # both
bash paper/build.sh clean        # remove aux files
uv run python paper/tables/make_main_tables.py   # regenerate the four generated main-text tables
```

Gotchas: keep `\clearpage` between the generated `\input`s in the appendix (~56
consecutive floats deadlock the two-column output routine); use `\dag` in text mode,
never `$\dag$`; keep the post-cutoff table at `\scriptsize` (a wider version overflows the
column and prints over the neighbouring text).

## Layout

| Path | Contents |
|---|---|
| `main.tex` | Document class, preamble, `\TODO`/`\pending` macros, `\input`s all sections |
| `refs.bib` | Bibliography, built from DESIGN.md §13 |
| `sections/` | `00`–`05` main text, `09` Limitations, `10` Ethics, `A1` appendix |
| `tables/*_main.tex` | Generated main-text tables (`make_main_tables.py` reads `data/results/*.csv`) |
| `tables/code_audit.tex` | Rows generated by `make_code_audit.py` from `code_availability.csv` (caption hand-written) |
| `tables/substrate.tex` | Hand-curated from `result_table_5r*.csv` (run ids in the header) |
| `tables/{baselines,text,audio,convention,repro,faithful,repro_controls,earnings25_audio,lookahead_assumed,code_audit}.tex` | Appendix tables, curated from the CSVs named in each header |
| `figures/problems.tex` | Figure 1 (TikZ): the day-0 anchor and the company-overlap problem |
| `figures/fig_{swaps,repro,ladder}.pdf` | Result figures generated by `figures/make_figures.py` from `data/results/*.csv` (matplotlib, in the `dev` group; palette validated with the dataviz checker) |
| `figures/pipeline.tex` | TikZ stage-ladder schematic (appendix) |
| `archive/` | Frozen PDFs of superseded drafts |

The appendix also `\input`s the auto-generated grids `../data/results/result_table_{1,2,3,4}.tex`
(emitted by `ecvol report`, byte-identical and CI-guarded). If you re-run a result
command and numbers change, re-run `make_main_tables.py` and update the curated tables
to match.

## Drafting conventions

- `\TODO{...}` (red) and `\pending{...}` (orange) are hidden when `\draftmode` is set
  false in `main.tex`. None remain in the condensed draft.
- Line numbers and the anonymous author line come from the `review` class option.
- Every number in the prose traces to `data/results/` or a JOURNAL-recorded audit.

## Style files

`acl.sty` and `acl_natbib.bst` are verbatim copies of the ACL Rolling Review template
(github.com/acl-org/acl-style-files, branch `master`, fetched 2026-10-09). The style loads
geometry, caption, natbib, hyperref and lineno itself and sets the bibliography style, so
`main.tex` must not load or set those again. The self-contained 10pt layout used before
the switch is in git history (commit acb0139 and earlier).
