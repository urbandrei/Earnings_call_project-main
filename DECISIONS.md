# DECISIONS.md — Project Decision Log

**Append-only.** This file is the single place where the project's design contract ([DESIGN.md](DESIGN.md)) is amended. DESIGN.md itself is never silently edited — if reality diverges from the design, the divergence is recorded here first, then (if needed) DESIGN.md is updated with a reference to the entry.

## What gets an entry

- Any deviation from, or amendment to, DESIGN.md (data sources, targets, models, protocols, gates).
- Scope changes: adding/removing/materially changing a task in [TASKS.md](TASKS.md); pulling anything from the out-of-scope list (DESIGN.md §3.6).
- Promotions: an exploration result (see CLAUDE.md exploration policy) becoming part of the pipeline or the paper.
- Spend approvals: cloud compute bursts, paid API usage — with budget and hypothesis.
- Gate outcomes: the §4 framing gate, Stage-6 go/no-go, acceptance-test changes.

## Entry format

```
YYYY-MM-DD — decision — rationale — alternatives rejected
```

One entry per decision; link supporting material (journal entries, run artifacts, papers) inline. Never edit or delete past entries — if a decision is reversed, append a new entry that says so and why.

## 2026-09-16 — Controls sprint (T6R.4): scope set by the user; protocol decided inside the sprint

**Decision (user, AskUserQuestion 2026-09-16).** Re-run **all five** reproduced models under embargoed and ticker-disjoint evaluation on their own data, **cheapest first** (HTML faithful → Sawhney port → SCSS → DialogueGAT port → KeFVP MAEC). **Protocol (decided here, per the policy).**
1. **Change only the split.** Each model keeps the configuration that reproduced (or best approached) its published cell — its "anchor" — and every other hyperparameter, label file and input stays identical. The anchor split is re-run in the same invocation, so every delta is split-only and same-code, same-machine.
2. **Controlled conditions:** `embargoed` — chronological, with train/val calls whose τ≤30 target window could reach the first evaluation date removed (EC/FinCall: our committed `*_temporal.csv`, 30-session embargo); `ticker_disjoint` — no evaluation ticker appears in training (our committed `*_ticker_disjoint.csv`). Where a model's own dataset has no committed split of ours (SCSS's DEC rolling quarters, KeFVP's MAEC-15/16 subsets), the same two rules are applied *inside its own protocol* by rewriting only the split/mask columns its code reads — the authors' code is not touched.
3. **Per model:** HTML — anchor `code` hyperparameters (dropout 0; the only condition whose text+audio cell reproduces), plus `published_split` for reference, text and text+audio. Sawhney — val-tuned ensemble is the controlled number (test-tuning is itself leakage); test-tuned kept for parity. SCSS — TSMixer/TMLP masks: embargo drops pre-quarter calls within 30 sessions of the test quarter; ticker-disjoint assigns tickers to a seeded held-out third, trains on the rest, tests on the held-out third, and the anchor is re-scored on the *same* held-out third; STPEV/Aug_STPEV stay reason-coded. DialogueGAT — FinCall temporal/ticker-disjoint vs its per-year anchor. KeFVP — MAEC-15/16 re-split within their call sets.
4. **Persistence on every cell**, and seed spread reported, so a delta is read against both the floor and the noise.

**Rejected:** re-tuning hyperparameters per controlled split (would confound the split effect with a tuning effect); evaluating on our FinCall/MAEC splits for models trained on EC/MAEC-15/16 (the 2026-08-23 confound rule — each model on its own data).
